A single-line joke about office life, written for make.fun's "One-Line Office Jokes" bounty: the printer that only jams when the deadline is five minutes away — like it read the email first. The program writes exactly that line to `/output/entry.txt`, after a self-check that mirrors the competition gate (UTF-8, 1–199 characters, one line, not only whitespace).

## Run it

```sh
python3 main.py
```
